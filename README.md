# Thu Chi Gia Đình

Sổ thu chi gia đình, chạy trên trình duyệt, ưu tiên điện thoại.

- Tài khoản ngân hàng, ví điện tử, tiền mặt và thẻ tín dụng
- Thu, chi, chuyển khoản; danh mục hai cấp có màu; ngân sách tháng
- Dữ liệu lưu trên máy. Sao lưu và khôi phục bằng file JSON
- Xuất báo cáo tháng ra PDF

```bash
npm install
npm run dev
```

Mở http://localhost:5173. Kiểm tra bằng `npm test`, đóng gói bằng `npm run build`.

Trang công khai, sau khi bật GitHub Pages: https://hoangtuan8911.github.io/ThuChiGiaDinh/

Repo đang riêng tư thì link đó không chạy. Đổi repo thành công khai, vào Settings → Pages và chọn Source là GitHub Actions. Mỗi lần đẩy lên `main`, workflow đăng bản mới.

Icon trong `public/` là icon tạm, thay khi có file chính thức.
